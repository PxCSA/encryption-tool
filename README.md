# Encryption Tool 🔐(for educational purpose only )

A simple Caesar Cipher encryption and decryption tool built in Python.

## Features
- Encrypt any message using Caesar Cipher
- Decrypt any encrypted message
- Custom shift number support
- Simple menu driven interface

## Usage
```bash
python encryption_tool.py
```

## Example
Original  : HELLO
Encrypted : KHOOR
Shift     : 3
## What is Caesar Cipher?
Caesar Cipher is one of the oldest encryption techniques.
It shifts every letter by a fixed number to create a secret message.
